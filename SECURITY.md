# Security reporting

Do not post API keys, tokens, personal documents, biometric data or trading records in an issue.
Use GitHub's private vulnerability reporting if the Security tab offers it. Otherwise, open
a minimal issue asking for a private reporting channel without including the exploit or secret.

The community server binds to loopback and checks the local origin and a session token.
Do not expose it through a public proxy. The application is not a multi-user security boundary.
Dependency and model updates require review; integrity checks do not establish model accuracy.
