# Contributing

Open an issue with the expected behavior, actual behavior, platform and a minimal reproduction.
Use synthetic data. Keep changes focused, preserve license notices and include relevant checks.
Never submit real API credentials, portfolios, face samples, chat histories or private paths.

Contributions must be compatible with this repository's noncommercial license. Describe any
new dependency and its license. A passing test is evidence of the tested behavior, not a
claim of trading profitability, biometric accuracy or general production readiness.
